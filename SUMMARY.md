## 🚀 Démarrage Rapide

### 1. Installer et Lancer
```bash
npm install
npm run dev
```

### 2. Ouvrir dans le navigateur
```
http://localhost:3000
```

### 3. Personnaliser
- Modifiez `src/app/page.tsx` pour vos expériences
- Modifiez `src/app/projects/page.tsx` pour vos projets
- Changez les couleurs dans `tailwind.config.js`

### 4. Déployer
```bash
# Sur Vercel (recommandé)
npm install -g vercel
vercel

# Ou sur Netlify
npm run build
# Déployez le dossier .next
```

## 🎨 Personnalisation Facile

### Changer les Couleurs
```javascript
// tailwind.config.js
colors: {
  accent: '#3b82f6',  // Bleu
  accentDark: '#1e40af',
}
```

### Ajouter des Expériences
```typescript
// src/app/page.tsx
const experiences = [
  {
    company: 'Votre Entreprise',
    role: 'Votre Rôle',
    // ...
  }
]
```

### Ajouter des Projets
```typescript
// src/app/projects/page.tsx
const projects = [
  {
    id: 'mon-projet',
    title: 'Titre',
    // ...
  }
]
```
