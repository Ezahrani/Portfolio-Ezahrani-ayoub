## 🎯 Par Cas d'Usage

### Je veux démarrer rapidement
1. Lisez [QUICK_START.md](QUICK_START.md)
2. Exécutez `npm install && npm run dev`
3. Ouvrez `http://localhost:3000`

### Je veux personnaliser le contenu
1. Consultez [CUSTOMIZATION.md](CUSTOMIZATION.md)
2. Modifiez `src/app/page.tsx`
3. Modifiez `src/app/projects/page.tsx`

### Je veux changer les couleurs
1. Ouvrez `tailwind.config.js`
2. Modifiez la valeur `accent`
3. Testez avec `npm run dev`

### Je veux déployer
1. Lisez [DEPLOYMENT.md](DEPLOYMENT.md)
2. Choisissez Vercel ou Netlify
3. Suivez les étapes

### Je veux comprendre la structure

2. Explorez les fichiers

2. Copiez la commande
